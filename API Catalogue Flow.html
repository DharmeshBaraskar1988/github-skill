From .NET source code to one approved global canonical model, run by GitHub Copilot agents. Every blue step repeats its validation until it passes. You wait only at the amber points. Click any box for its inputs, outputs and folders.

Where you wait

Three kinds of pause

WaitWhyHow it ends
ReviewApprovals are human-only; agents never approve.Reviewers decide in the alignment HTML (Approve all… or per entity) or Excel, then /import-review.
Re-reviewA source model changed after approval; that row turns "changed" and the canonical model drops to draft.Reviewers decide the changed rows again.
ReleaseOther regions and the global model only use frozen releases.You ask the canonical agent to release (version in regions/<REGION>.yaml).
Loop limitA validator kept failing after maxIterations.The agent reports the open errors; fix the input and rerun.

Everything else runs straight through: each step starts only when the previous step's validation.json says pass.
