Example OpenAPI specs that show your HOUSE STYLE. Discovery learns conventions from them and never copies them.
- `_global/` - applies to every region
- `<REGION>/` (e.g. `EU/`, `UK/`) - extra examples for that region only (read together with `_global/`)
`house-style-example.yaml` is an invented example - replace it with a few real, good specs of your own.
