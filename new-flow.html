Where you wait

Every step pauses for review

WaitWhyHow it ends
Step reviewCommon to every step: once validation passes, a named reviewer signs off the step's output. Agents never approve.Reviewer runs /approve-step, or /request-changes with comments; the agent reruns with them and the step returns for review.
ACORD decisionsStep 5 goes further: entity-by-entity decisions, human-only.Reviewers decide in the alignment HTML (Approve all… or per entity) or Excel, then /import-review.
Re-reviewA source model changed after approval; that row turns "changed" and the canonical model drops to draft.Reviewers decide the changed rows again.
ReleaseOther regions and the global model only use frozen releases.You ask the canonical agent to release (version in regions/<REGION>.yaml).
Loop limitA validator kept failing after maxIterations.The agent reports the open errors; fix the input and rerun.

A step starts only when the previous step's validation.json says pass and its review.yaml says approved. If a step's output is regenerated, its approval resets to pending.

Artifact reference

Every file, its extension and who writes it

Made by: script = generated, never edit by hand · agent = the Copilot agent maintains it with notes · people = reviewers' decisions · you = inputs you provide. Every step also writes validation.json and gets a review.yaml sign-off from people.
